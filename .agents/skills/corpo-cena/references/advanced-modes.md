# advanced-modes

Densidade/protagonismo regulam sujeitos, não cenário. Perfil recorrente é ficha textual, sem garantia biométrica. Continuidade usa descrição consistente em cada imagem sem fundir perspectivas. Comparação visual exige duas imagens; não é detecção geométrica automática. Adaptação a ferramenta deve distinguir linguagem geral de parâmetros oficiais verificados. Máscara descrita não significa máscara executada.
