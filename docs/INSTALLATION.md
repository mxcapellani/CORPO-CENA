# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/CORPO-CENA.git
cd CORPO-CENA
```
Copiar `.agents/skills/corpo-cena` para o projeto alvo. Para hosts sem descoberta automática, carregar SKILL.md explicitamente. Visão e editor dependem do ambiente. Nenhuma chave exigida para uso textual.
Atualizar preservando mudanças locais, consultar CHANGELOG e repetir testes do README. Python/PyYAML são requisitos só da manutenção, não dos prompts em tempo de uso.
